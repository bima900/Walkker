# Walkker

Procedural walk cycles for **Rigify** rigs in Blender.

Walkker generates a looping, in-place walk cycle as regular keyframes (with a Cycles
modifier), so you can keep editing it in the Graph Editor or Dope Sheet.

> Status: early (v0.1.0). Root stays still; moving root and foot locking are planned.

## Features
- Foot IK trajectory with stance/swing phases
- Hip bounce, sway and rotation; chest counter-twist
- Pendulum arm swing, plus **Arm Space** to control hand-to-body distance
- Rigify finger support (relaxed curl and lagging sway)
- Works with Rigify-generated rigs, including custom ones as long as Rigify bone names are kept

## Requirements
- Blender 5.0 or newer (developed against 5.3)
- A rig generated by Rigify

## Install
1. Download `walkker.zip` from the Releases page (or build it, see below).
2. In Blender: Preferences > Get Extensions > drop-down arrow > **Install from Disk**.
3. Open the 3D Viewport sidebar (`N`) > **Walkker** tab.

## Usage
1. Pick your Rigify armature in **Rig**.
2. Adjust the parameters.
3. Click **Generate Walk**.

Bones used: `torso`, `hips`, `chest`, `foot_ik.L/R`, `hand_ik.L/R`, and finger bones
`thumb.01-03`, `f_index|f_middle|f_ring|f_pinky.01-03` (`.L/.R`). Missing optional bones
are skipped.

## Build from source
```
cd walkker
zip -r ../walkker.zip . -x "__pycache__/*" "*.pyc"
```
or `blender --command extension build` inside the `walkker/` folder.
